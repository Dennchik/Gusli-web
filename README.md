# Gusli-web

Gusli-web site

# Рекомендации по приоритету

1. Вырезать из app.js весь мёртвый квиз-код (или доделать квиз и вернуть разметку) — это уберёт и TypeError, и
   баг с btn.
2. Починить ESLint: поставить @eslint/js, выпилить React/TS-плагины, исправить #src.
3. Прочистить package.json от неиспользуемых пакетов — это заметно ускорит npm install и обновления.
4. Добавить в .gitignore: build/, public/css/, src/scss/core/_fonts.scss, public/img/*.webp (если webp-исходники
   храните) и сделать чистый коммит текущего состояния.
5. Дать hero-кнопкам реальные якоря (#brief, #cases) и заменить контактные плейсхолдеры.
